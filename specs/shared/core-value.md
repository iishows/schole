## 1. 一句话核心价值

> **让每个孩子都有一个 AI 班主任"小诺姐姐" + 2 个 AI 同学陪着写作业——错题有人用生活比喻讲，作业不再孤军奋战，家长不再陪写作业吼叫。**

---

## 2. 3 个不可替代的价值

| # | 价值 | 视角 | 一句话 |
|---|---|---|---|
| 1 | **孩子不再孤军奋战** | 孩子 | 有 1 老师 + 2 同学陪着 |
| 2 | **错题真正消化** | 学习 | Socratic + 同学故意犯错 + 间隔重复 |
| 3 | **家长不再焦虑** | 家长 | 从陪写作业吼叫变成下班看 3 卡片 |

## 3. 解决什么问题（3 层）

### 3.1 表层问题（家长说的）

- "我下班回家孩子作业还没做完"
- "应用题我自己也讲不清"
- "错题本抄完没人讲"
- "我编不出新故事"
- "讲太久我自己累"

### 3.2 中层问题（家长不会说的）

| 痛点 | 强度 |
|---|---|
| **家长缺失陪伴**（白天上班/晚上累）| 🔴🔴🔴 |
| **孩子孤军奋战**（一个人写作业）| 🔴🔴🔴 |
| **错题积压**（没人讲，下次还错）| 🔴🔴🔴 |
| **教育焦虑**（怕掉队）| 🔴🔴 |
| **家长自责**（觉得自己不称职）| 🔴🔴 |

### 3.3 深层问题（社会问题）

| 问题 | 含义 |
|---|---|
| 现代家庭结构变化 | 双职工、独生、远距离——"家庭辅导"功能瓦解 |
| 教育责任个人化 | 学校只管上课，辅导全部转嫁家长 |
| 教育资源不均 | 城市 vs 乡镇、名校 vs 普通校、家庭收入差异 |
| 家长能力与期望鸿沟 | 想辅导但不会 / 想陪但没空 |

**一句话总结**：**"家长该做但做不到"**——这是现代教育最大的缺口。

## 4. 3 个核心场景

### 4.1 场景 1：孩子卡在错题（放学后，独自一人）

```
时间：16:00-19:00 放学后
用户：6-12 岁孩子，独自面对作业
痛点：没人讲、应用题看不懂、分母不会通分
解决：小诺姐姐 Socratic 引导 + 小红故意问"为什么" + 阿泽故意犯同样错 + 白板画披萨
```

### 4.2 场景 2：孩子复习错题（周末，家长有空）

```
时间：周末 10:00-12:00
用户：6-12 岁孩子 + 家长
痛点：错题本抄完没人讲、家长也讲不清
解决：错题本 + 间隔重复自动调度 + 同学一起复习
```

### 4.3 场景 3：家长下班看进度（晚上 19:00）

```
时间：晚上 19:00-20:00
用户：30-40 岁家长
痛点：不知道孩子今天学了什么、哪里卡住
解决：公众号推送 3 卡片（掌握度 + 错题 TOP 3 + 改进建议）
```

## 5. 5 个核心功能

| # | 核心功能 | 对应痛点 | OpenMAIC 能力 |
|---|---|---|---|
| 1 | **1 mentor + 2 buddies 实时互动** | 孩子不孤单 | Director graph + Agent runtime |
| 2 | **错题本 + Socratic 引导** | 错题没人讲 | DSL speech + spotlight + Storage |
| 3 | **简化 Whiteboard 辅助讲解** | 应用题看不懂 | wb_draw_shape（披萨图 SVG）|
| 4 | **间隔重复 + 错题归档** | 错题积压 | 调度器（艾宾浩斯 1/3/7/14 天）|
| 5 | **学习报告 + 公众号周报** | 家长看不到掌握度 | 模板消息 + 3 卡片 |

---

## 6. 5 个产品原则（不可妥协）

| # | 原则 | 说明 |
|---|---|---|
| 1 | **多 agent > 单 agent** | 5 角色互动是核心差异化，不能简化 |
| 2 | **Socratic > 直接给答案** | 不直接给答案，逼孩子自己想 |
| 3 | **同学故意犯错 > 标准答案** | Peer teaching 效果最好 |
| 4 | **白板辅助 > 纯文字** | 披萨图让分数可视化 |
| 5 | **家长看报告 > 陪写作业** | 解放家长，不陪写作业 |

## 7. 与竞品的差异（不可替代）

### 7.1 vs 通用 LLM（ChatGPT / Kimi）

| 维度 | 通用 LLM | OpenMAIC |
|---|---|---|
| Socratic 引导 | ❌ 直接给答案 | ✅ 8 条规则严格遵守 |
| 多角色互动 | ❌ 单 agent | ✅ 5 角色 |
| 错题管理 | ❌ 无 | ✅ 错题本 + 间隔重复 |
| 学习报告 | ❌ 无 | ✅ 家长周报 |
| PIPL 合规 | ❌ 数据出境 | ✅ 阿里云 cn-region |
| 双减边界 | ❌ 教新课 | ✅ 只辅导 |

### 7.2 vs 学习机（科大讯飞 / 学而思）

| 维度 | 学习机 | OpenMAIC |
|---|---|---|
| 形态 | 硬件 ¥3000-8000 | Web PWA ¥99/月 |
| 内容 | 预置课件 | AI Socratic 实时讲解 |
| 互动 | 标准化 | 个性化 |
| 同学 | 无 | 2 AI 同学 |
| 升级 | OTA | 实时 |

### 7.3 vs 在线辅导（猿辅导 / 掌门）

| 维度 | 在线辅导 | OpenMAIC |
|---|---|---|
| 形式 | 真人 1v1 / 小班 | AI 24/7 |
| 价格 | ¥100-300/课 | ¥99/月（无限）|
| 时间 | 固定时段 | 随时 |
| 错题讲解 | 临时 | 错题本 + 间隔重复 |
| 监管 | 🔴 学科辅导红线 | 🟢 辅导定位 |

### 7.4 OpenMAIC 不可替代的核心能力

| 能力 | 为什么不可替代 |
|---|---|
| **多 agent 实时互动** | 不是 LLM 单轮对话，是 5 角色协调 |
| **DSL action 协议** | speech + spotlight + wb_draw_shape 同步驱动 |
| **Director graph** | 控制多轮多角色节奏（不是简单 prompt）|

## 12. 监管（辅导定位，不踩红线）

| 监管 | 应对 |
|---|---|
| **PIPL** | 强制 consent + 数据本地化 + 不出境 |
| **双减** | **严格"辅导"定位**：错题讲解 + 复习巩固，**不教新课** |
| **ICP** | 阿里云备案 |
| **微信** | 公众号模板消息 + 微信支付商户号 |
| **内容审核** | 班主任/同学输出过滤（阿里云内容安全 + 关键词）|
| **时长** | 每天 ≤ 60 分钟 + 21:00-7:00 禁用 |

| 可以说 ✅ | 别说 ❌ |

| "复习学校讲过的内容" | "讲新课" |
| "错题讲解" | "包提分" |
| "孩子不再孤军奋战" | "名师 1v1" |
