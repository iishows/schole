## 1. 概述

### 1.1 产品定位

把 OpenMAIC 从"AI 课堂生成器"演进为"课后伴学产品"。核心场景：**中国双职工家庭**，孩子放学回家后没人辅导作业，AI 班主任 + AI 同伴陪伴学习，家长通过**微信小程序**接收每日报告。

### 1.2 目标用户

- **学生**：4-6 年级（10-12 岁），中国公立学校人教版 / 苏教版 / 北师大版
- **家长**：双职工，30-40 岁，微信重度用户，对辅导有焦虑但能力/时间有限
- **运营/老师**：内容运营 + 学情分析师，PC Web 后台

### 1.3 核心痛点

| 角色 | 痛点 | 本产品解法 |
|---|---|---|
| 学生 | 课上听懂，作业不会；没人陪 | 苏格拉底式引导 + 同伴陪伴 |
| 家长 | 想辅导但不会 / 没时间；情绪化辅导 | AI 替辅导；微信日报告诉家长怎么接话 |
| 老师 | 班级 40-50 人，顾不过来 | 一对一定制化（间接，通过 AI 班主任模拟） |

### 1.4 设计决策摘要

| 决策 | 选项 | 选择 | 理由 |
|---|---|---|---|
| 教室布局 | C1 / C2 / C3 | **C3 浮气泡 + 紧凑输入** | 真教室"贴"着人聊，不集中消息流 |
| "真人"实现 | 单老师 / 单老师+多同伴 / 三位一体 | **班主任 + 2 同伴 + 家长助手** | 差异化最强，multi-agent 已有基础 |
| MVP 范围 | A:1-2周 / B:3-4周 / C:8-12周 | **B 核心 MVP** | 错题闭环 + 同伴感 + 家长日报都有 |
| 学生入口 | 找课程 / 继续上次 | **继续上次（hero CTA）** | 零思考进入 |
| 聊天位置 | 底部 / 右下 / 浮气泡 | **浮气泡 + 完整历史抽屉** | 真教室感最强 |
| 家长通道 | Web / 小程序 / 公众号 | **微信小程序 + 长期订阅** | 不装 APP，合规清晰，推送稳定 |
| 推送频率 | 每天 / 每周 | **每周 1-3 次（家长可设）** | 防骚扰 + 家长不疲劳 |
| 数据存储 | 纯 client IndexedDB / 跨设备 | **服务端 PostgreSQL + 客户端缓存** | 跨设备同步 |
| **角色创建模型** | A 平台预制 / B LLM 自动 / C 预制+微调 | **C 预制 + 微调** | 质量 + 个性化平衡 |
| **家长改 mentor 人设** | ✅ / ❌ | **✅ 可以** | 改名字 + 性格细节 + voice |
| **mentor 记忆隔离** | 严格隔离 / 共享 | **严格隔离** | 法规要求（个保法）+ 防泄漏 |
| **家长看 mentor 对话** | 摘要 / 完整 | **默认摘要 + 授权看完整** | 隐私默认保护 |
| **运营 RBAC** | 全平台 / 按班级 | **按班级分组** | 数据最小化原则 |

### 1.5 Mockup 文件清单

- `mockups/classroom-layout-c3.html` — 教室布局 C3（定版）— 班主任 + 2 同学（**北京/上海城市感**）
- `mockups/student-home.html` — 学生开始页（**每周错题汇总卡** + 章节标签）
- `mockups/admin-console.html` — 管理后台
- `mockups/wechat-push.html` — 微信小程序订阅消息推送样式
- `mockups/home-school-*.html` — 跨市场参考（设计差异对照，不在 cn 实施范围）

## 3. 角色与权限（核心架构）

### 3.1 角色清单

**真人 4 类**：
- **学生**（user.role = student）
- **家长**（user.role = parent）
- **运营/老师**（user.role = operator）
- **平台超管**（user.role = admin）

**虚拟 5 类**：
- **班主任/Mentor**（role = mentor）— 学生专属，**1 对 1**
- **同学/Study Buddy**（role = buddy）— 学生专属，**1 学生对 2-3 个**
- **家长助手**（role = parent_assistant）— 家长专属，1 对 1
- **角色模板**（role = template）— 平台所有，运营可编辑
- **运营助手**（role = operator_assistant）— v2+，平台所有

### 3.2 Owner 模型（数据隔离关键）

| 角色 | 类型 | owner | 可见范围 |
|---|---|---|---|
| 学生专属 mentor | 学生专属 | 该学生 | 仅该学生对话 |
| 学生专属 buddy | 学生专属 | 该学生 | 仅该学生对话 |
| 家长助手 | 家长专属 | 该家长 | 仅该家长对话 |
| mentor 模板 | 平台 | NULL | 所有人可见（只读） |
| buddy 模板 | 平台 | NULL | 所有人可见（只读） |

**关键规则**：
- 学生专属角色**严格隔离**：Emma 在 Lily 对话里提到 Lily，**绝不能在 Noah 的对话里提到 Lily**
- 模板是平台所有，**用户 onboarding 时克隆模板**为学生专属实例（保留原模板 + 副本可改）
- 克隆链：`source_template_id` 字段记录来源，方便追踪

### 3.3 权限矩阵

| 操作 | 学生 | 家长 | 运营 | 超管 |
|---|---|---|---|---|
| 看自己错题 | ✅ 写 | ✅ 看 | ✅ 所管学生 | ✅ 全部 |
| 改错题错因 | ✅ 标记掌握 | ❌ | ✅ 编辑 | ✅ |
| 看其他孩子错题 | ❌ | ❌ | ✅ 所管 | ✅ 全部 |
| 跟自己的 mentor 聊 | ✅ | ❌ | ❌ | ❌ |
| 看 mentor 完整对话 | ❌ | ✅ 摘要；**授权后**完整 | ❌ | ❌ |
| 改自己孩子的 mentor 人设 | ❌ | ✅（名字/性格细节/voice） | ✅ 改模板 | ✅ |
| 创建新 mentor 模板 | ❌ | ❌ | ✅ | ✅ |
| 看 mentor 模板库 | ✅ 浏览 | ✅ | ✅ 编辑 | ✅ |
| 接收推送日报 | ❌ | ✅ 默认 | ✅ 手动推 | ✅ |
| 推送家长日报 | ❌ | ❌ | ✅ | ✅ |

### 3.4 角色创建流程（用户 onboarding）

```
[Step 1] 家长注册 + 选套餐
   ↓
```

## 4. 功能模块

### 4.1 学生专属角色系统

**班主任（固定 1 个）**

- **风格选择**：5-10 个预制模板（温柔姐姐 / 严格老师 / 搞笑大叔 / 学术派 / ...）
- **长期记忆**：
  - 学生基本信息（年级 / 兴趣 / 性格 / 最近学校的事）
  - 错题本 + 错因
  - 知识点掌握度
  - 情绪历史 + 关键发言引用
- **苏格拉底 prompt**（核心）：
  ```
  你是一个温柔的小学老师。你的学生会问你作业题。
  严格遵守：
  1. 不直接给答案
  2. 先问"你怎么想的？"
  3. 必要时给提示（一句话）
  4. 学生实在不会，分步拆解思路
  5. 学生错了不批评，反问"为什么这么算？"
  6. 学生对了简单肯定，然后追问"如果分母不同呢？"
  7. 情绪检测：连续 2 题错就切换到鼓励语气
  8. 记忆隔离：你只认识这一个学生，不要泄漏其他学生的信息
  ```

**同学（固定 2-3 个）**

- **风格选择**：5-8 个预制模板（爱问型 / 粗心型 / 细心型 / 活泼型 / 安静型）
- **地理感**（v1.1+）：绑定学生城市 → 给同学加城市（如"小红（北京）/ 小亮（上海）"）
- **性格固定，但会"成长"**——根据孩子反馈调整互动方式
- **whisper 视觉**：浮气泡 + 虚线连接（不集中在右下）
- **触发**：director 在 teacher 说完后概率让同学插嘴（whisper / 反驳 / 补充）

**家长助手**（独立通道）

- 单独的 system prompt
- **不在 chat 里发言**——只在家长小程序里以"小助理"身份回复
- 功能：
  - 给家长讲错题怎么讲
  - 心理侧建议（孩子最近厌学怎么办）
  - 整理孩子的问题清单

### 4.2 作业模式（核心）

**学生入口**：
- 拍照（OCR + LLM 解析）
- 打字输入题目
- 选错题本里旧的题
- 直接念题（语音输入）

**AI 引导流程**：
1. 学生提问
2. AI 不直接答："你怎么想的？"
3. 学生答
4. 答对 → 肯定 + 追问（举一反三）
5. 答错 → 反问"为什么这么算？" → 学生解释 → 指出错误思路 → 引导正确思路
6. 实在不会 → 分步拆解思路（3-5 步）
7. 完成后 → 自动入错题本（标注错因 + **人教版章节代码**）
8. 错因分类：分母通分错 / 计算粗心 / 概念混淆 / 单位换算错 / 题意不理解

**错题归因引擎**（新增模块）：
- 学生答错后 + 学生解释的思路 → LLM 推断错因
- 错因 5 类标签 + 详细文字说明
- 同一错因的题 → 复习时按错因聚合

### 4.3 复习模式（艾宾浩斯）

**算法**：
- 错题入本时：标记熟练度 0%
- 复习完成（答对）：熟练度 +20%，下次复习间隔按艾宾浩斯延长
- 复习答错：熟练度 -10%，下次复习间隔缩短
- 熟练度 100% + 3 次答对 → 出错题本

**每日复习队列**：
- 每天首页"📕 今日复习"显示 3-5 道待复习题
- 按"应该复习时间"排序（最久的优先）
- 复习模式 UI：单题循环，不显示完整错题本

**每周错题汇总卡**（v1.1+）：
- 首页顶部 +1 张"本周错题汇总"卡
- 显示本周错题数 / 错因分布 / 主要章节
- 一键进入复习

### 4.4 番茄钟模式

- **25min 学习 + 5min 休息**（4-6 年级适用）
- 班主任期间主动关心（"已经 20 分钟了，要不要休息？"）
- 家长可设上限（默认 25min/天）
- 超时：弹"今天够了，明天继续？"提示

### 4.5 朗读评测（v2 范围）

- 英语单词 / 语文课文跟读
- 语音评测：发音准确度 + 流利度
- 跟 OpenMAIC 现有 TTS 集成

### 4.6 知识点图谱（粗粒度）

**schema**：
```ts
interface KnowledgePoint {
  id: string;       // e.g. "math.4.fraction.adding.different-denominator"
  subject: string;  // "math" | "chinese" | "english"
  grade: number;
  textbookVersion: string;  // "人教版" | "苏教版" | "北师大版"
  chapterCode: string;       // "4-NF-A-1"
  name: string;
  parent: string | null;     // 树形
}
```

**展示**：

### 4.8 模式切换（作业 / 复习 / 自由）

**作业模式**（默认）：右半屏显示当前题目 + 错题本
**复习模式**：右半屏显示艾宾浩斯复习队列（错题循环），无新错题入本
**自由模式**：右半屏空白或聊天抽屉展开，纯聊天陪伴

### 4.9 家长微信小程序

**小程序功能**：
- 学习日报（今日时长 / 错题 / 弱项 / 情绪 / 老师金句）
- 错题本查看（家长看孩子的错题，建议怎么辅导）
- 学情图谱（按章节）
- 推送设置（频率 / 时间）
- 留言给小诺姐姐（双向 → 转 AI 处理）
- **导师对话权限**：默认看摘要 + 情绪时间线；申请授权后看完整对话（家长会决定要不要给）

**推送模板**（订阅消息）：

**频率策略**：
- 默认：每周一三五 21:00
- 家长可改：每天 / 每周 / 不推送
- 紧急通知例外（情绪低落 / 反复错）→ 即时推

## 5. 错误处理

| 场景 | 处理 |
|---|---|
| LLM 响应超时 | 重试 1 次 + 显示"老师在思考..."占位 + 兜底文案 |
| LLM 输出 type 错误 | storage sanitize 兜底（commit 423b86b1） |
| 微信 access_token 过期 | 缓存 7200s，过期前 5min 刷新；失败重试 1 次 |
| 家长退订 | push_subscriptions.enabled = false；保留数据 |
| 学生拍照 OCR 失败 | 提示重新拍，建议光线 + 角度 |
| 错题归因 LLM 返回不确定 | 标记"待人工确认"，先归"其他" |
| 推送发送失败 | 重试 3 次（指数退避）；失败记日志 |
| 跨学生泄漏 mentor 记忆 | **audit_logs 告警 + 立即冻结会话** |
| 家长未授权看完整对话 | mentor 对话只能返回摘要 + 情绪时间线 |
| 运营越权访问其他班级学生 | RBAC 中间件拒绝 + 记 audit_log |
| 学生尝试访问其他学生数据 | RBAC 中间件拒绝 |

## 8. 风险与依赖

| 风险 | 影响 | 缓解 |
|---|---|---|
| 微信长期订阅申请被拒 | Phase 2 延期 | 备选：公众号模板消息 |
| LLM 苏格拉底引导效果不稳定 | 核心体验差 | prompt 多次迭代 + few-shot examples + 人工评测 |
| 错题归因准确率不达标 | 家长报告不准 | 标注"AI 推断"，家长可手动修正 |
| 端到端延迟过高 | 学生不耐烦 | 流式 + 占位动画 + 番茄钟缓冲 |
| 知识图谱维护成本 | 运营负担 | 启动时按章节粗粒度 |
| 国内政策变化（双减 / AI 监管） | 产品合规 | 保持"AI 辅导"而非"AI 教学"定位 |
| **跨学生数据泄漏** | **致命**（合规 + 信任） | RBAC + audit_logs + 0 容忍测试 |
| mentor 记忆 LLM 跨学生串 | 严重 | prompt 强化"只认一个学生" + 服务端 owner_id 校验 |
