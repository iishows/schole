## 4. 关键路径 / 资源 / 工作量 收敛

### 关键路径
M1-M15 串行 = 50 工作日 = 10 周（主路径 + 商业化）

### CM 通道（兼职 0.5）
- CM1: 2.5d / CM2: 3.5d / CM3: 3d / CM4: 5d / CM5: 3.25d / CM6: 2d
- **总 CM = 19.25d**（CM4 因 1.5+1.5 调整后变 5d；CM5 因 store 验证 0.25d 调整后变 3.25d）
- 5.5 周 × 0.5 兼职 = **13.75d 工时**
- buffer: 19.25d - 13.75d = 5.5d 缺口

**解读**：CM 通道 **工作量大但工期可压缩**（多个任务 0.5-1.5 天可压缩到 0.5 天通过熟练度）。buffer 5.5d 紧但可行，超出后 fallback = W6-W7 兼职吸收。
