## 0. 总览

### 0.1 4 类角色 × 4 类 SOP

| 角色 | SOP | 优先级 | Mockup | API |
|---|---|---|---|---|
| **孩子 K12**（6-12 岁）| 错题讲解 + 复习 | MVP | ✅ K-5 | ✅ M5/M6/M8/M9 |

## 1. 孩子 K12 SOP（核心场景）⭐

### 1.1 错题讲解 SOP（10 步）

**触发**：孩子卡在错题 / 拍照错题 / 手动输入错题

```
[第 1 步] 登录状态
   │
   │ ┌─────────────────────────────────────┐
   │ ├─ 家长帮登录（首次）               │
   │ ├─ 孩子设备锁自动登录（推荐）       │
   │ └─ 微信扫码登录                       │
   └─────────────────────────────────────┘
   ↓
[第 2 步] 进入主页
   │
   │ 主页显示：
   │ • 今日任务（错题 3 道待复习）
   │ • 快速操作（拍照 / 手动）
   │ • 历史错题
   └─────────────────────────────────────┘
   ↓
[第 3 步] 添加错题（2 选 1）
   │
   │ ┌─────────────────────────────────────┐
   │ ├─ 3a. 拍照错题（移动端）            │
   │ │   • 点击"📷 拍照"按钮              │
   │ │   • 调用相机拍摄作业                │
   │ │   • 选区 / 全图                      │
   │ │   • 上传阿里云 OSS                   │
   │ └─────────────────────────────────────┘
   │ ┌─────────────────────────────────────┐
   │ ├─ 3b. 手动输入错题（桌面端）        │
   │ │   • 点击"📝 手动"按钮              │
   │ │   • 输入题目文字                    │
   │ │   • 输入孩子答案                    │
   │ │   • 输入正确答案                    │
   │ └─────────────────────────────────────┘
   ↓
[第 4 步] OCR 识别（仅拍照）
   │
   │ • 调用 MiniMax multimodal vision API
   │ • 识别错题文字
   │ • 推断章节（4-NF-A-2 等）
   │ • 自动填充表单
   │
   │ 【异常】OCR 不准
   │   → 提示"识别可能不准，请核对"
   │   → 用户手动编辑
   ↓
[第 5 步] 选章节 + 提交
   │
   │ • 默认按 OCR 推断章节
   │ • 用户可手动调整
   │ • 提交 → 错题入库（mistakes 表）
   ↓
[第 6 步] 提示"现在让小诺姐姐讲吗？"
   │
   │ ┌─────────────────────────────────────┐
   │ ├─ "现在讲" → 进入 Socratic 对话    │
   │ ├─ "稍后讲" → 错题入库待复习        │
   │ └─ "跳过" → 标记为已看              │
   └─────────────────────────────────────┘
   ↓
[第 7 步] Socratic 对话（K-5 核心场景）
   │
   │ ┌─────────────────────────────────────┐
   │ │ 多轮 multi-agent 编排               │
   │ │                                     │
   │ │ Round 1: 小诺姐姐识别错题          │
   │ │   "你做错了 1/2 + 1/3 = 2/5，      │
   │ │    我们看看好不好？"              │
   │ │                                     │
   │ │ Round 2: 小红故意提问              │
   │ │   "为什么分母能直接相加呀？"       │
   │ │                                     │
   │ │ Round 3: 白板辅助（披萨图 SVG）    │
   │ │   • 触发 wb_draw_shape action      │
   │ │   • 画两个披萨（2 块 / 3 块）      │
   │ │   • spotlight 聚焦错题元素          │
   │ │                                     │
   │ │ Round 4: 阿泽故意犯同样错          │
   │ │   "我觉得是 2/5 没错呀？"          │
   │ │                                     │
   │ │ Round 5: 小诺姐姐引导              │
   │ │   "阿泽说 2/5，你们觉得对吗？"    │
   │ │   "块的大小不一样，不能直接相加"  │
   │ │                                     │
   │ │ Round 6: Socratic 继续              │
   │ │   "那我们要先做什么呢？"            │
   │ │                                     │
   │ │ Round 7+: 孩子输入 → 引导          │
   │ │   孩子答对 → 标记掌握 → 终止       │
   │ │   孩子答错 → 鼓励 → 继续           │
   │ └─────────────────────────────────────┘
   ↓
[第 8 步] 错题标记掌握
   │
   │ • 孩子答对 → mistakes.status = mastered
   │ • 错题归档到 mastered_at
   │ • 触发反馈"🎉 你自己想出来了！"
   ↓
[第 9 步] 错题进入间隔重复队列
   │
   │ spaced_repetition_queue：
   │   review_count = 0
   │   interval_days = 1 (艾宾浩斯)
   │   next_review_at = +1 天
   │
   │ 后续 1/3/7/14 天自动调度
   ↓
[第 10 步] 完成
   │
   │ • 错题本更新（已掌握 +1）
   │ • 提示"已掌握 5 道 · 待复习 2 道"
   │ • 30 分钟无操作 → 自动退出对话
   │ • 错题入库后触发周报计算
```

### 1.2 复习 SOP（4 步）

**触发**：间隔重复队列到时 / 家长推送

```
[第 1 步] 复习提醒
   │
   │ 来源：
   │ • Web PWA 通知（登录后）
   │ • 微信公众号模板消息（每周日晚 19:00）
   │ • 邮箱 digest
   ↓
[第 2 步] 进入复习界面
   │
   │ GET /api/review/queue
   │
   │ 显示：
   │ • 待复习列表（按 next_review_at 排序）
   │ • 优先级（按章节掌握度）
   │ • 复习按钮
   ↓
[第 3 步] 一题一题 Socratic 复盘
   │
   │ 与错题讲解 SOP 第 7 步类似
   │ 但 mentor 知道是复习，提示：
   │   "这是你 3 天前做错的题，还记得吗？"
   │   孩子答对 → review_count += 1
   │   孩子答错 → review_count = 0 (重置)
   ↓
[第 4 步] 更新间隔
   │
   │ 艾宾浩斯曲线：
   │   review_count = 0 → 1 天后
   │   review_count = 1 → 3 天后
   │   review_count = 2 → 7 天后
   │   review_count = 3 → 14 天后
   │   review_count >= 4 → mastered → 归档
   │
   │ 全部完成 → 公众号 / 邮箱推送"复习完成"
```

### 1.3 异常分支汇总

| 异常 | 检测 | 处理 |
|---|---|---|
| **拍照模糊** | OCR confidence < 0.5 | 提示"光线 / 角度问题"重拍 |
| **OCR 识别不准** | 字段缺失或字符乱码 | 提示手动编辑 |
| **孩子答错 2 次** | review_count == 2 | mentor 鼓励语气 + 生活比喻 |
| **孩子长时间不输入** | 30 分钟无消息 | 自动保存进度，提示休息 |
| **网络断** | SSE 连接断开 | 错题本地缓存，恢复后同步 |
| **LLM 响应超时** | > 30 秒 | 重试 1 次 + 提示"小诺姐姐想一下" |
| **director graph 出错** | 状态异常 | 兜底：单 agent 直接回复 |
| **多次尝试都失败** | 5 次连续错 | 提示"休息一下，明天继续" + 退出对话 |

```
   │
   │ 【MVP 限制】≤ 3 孩（家庭版套餐）

   │
   │ ┌─────────────────────────────────────┐

```

```
   │
   │ 上限 3 个

   ↓

   │
   │ 班主任：4 选 1
   │ 同学：4 选 2
   │ 默认组合推荐
   │
   │ 班主任锁定到学期末（防止中途换人）
   ↓
```

## 9. SOP 异常分支汇总

### 9.1 孩子 K12

| 异常 | 检测 | 处理 |
|---|---|---|
| 拍照模糊 | OCR confidence < 0.5 | 提示重拍 |
| OCR 不准 | 字段缺失 / 乱码 | 手动编辑 |
| 答错 2 次 | review_count == 2 | 鼓励语气 |
| 长时间不输入 | 30 分钟 | 自动保存 + 退出 |
| 网络断 | SSE 断开 | 本地缓存 + 同步 |
| LLM 超时 | > 30s | 重试 1 次 |
| Director 出错 | 状态异常 | 兜底：单 agent 回复 |
| 5 次连续错 | 错误率过高 | 提示休息 + 退出 |

### 9.2 家长

| 异常 | 处理 |
|---|---|
| 未添加孩子 | 7 天后公众号提醒 |
| 30 天试用未付费 | 公众号提醒 + 保留数据 |
| 微信支付失败 | 1 小时后重试 |
| PIPL 拒绝 | 必须同意才能进入 |
| 退款请求 | 7 天无理由退款 |

### 9.3 Onboarding

| 异常 | 处理 |
|---|---|
| 注册失败 3 次 | 锁定 1 小时 |
| 未添加孩子 | 7 天后提醒 |
| 未开始首课 | 3 天后引导 |
| 未选 persona | 提供"默认组合" |

### 9.4 系统

| 异常 | 处理 |
|---|---|
| MiniMax LLM 不稳定 | 备份 Anthropic Claude |
| OCR 服务异常 | 强制手动输入 |
| 微信模板消息失败 | 1 小时后重试 |
| 数据库连接失败 | 阿里云 RDS 多 AZ |
| PIPL 合规问题 | 法务 24h 响应 |

## 12. 关键术语

| 术语 | 定义 |
|---|---|
| **Onboarding** | 新用户从注册到首次完整使用产品的过程 |
| **PIPL** | 中华人民共和国个人信息保护法 |
| **PIPL consent** | PIPL 要求的 4 项明示同意 |
| **Socratic 引导** | 不直接给答案，通过问问题引导孩子自己想通 |

| **buddy** | AI 同学角色（小红 / 阿泽）|
| **mentor** | AI 班主任角色（小诺姐姐）|
| **director graph** | 多 agent 编排图（LangGraph StateGraph）|
| **DSL action** | OpenMAIC 课件动作协议（speech / spotlight 等）|
| **whiteboard** | 白板辅助讲解（披萨图 / 通分图）|
| **OCR** | 拍照识别（MiniMax multimodal vision）|
| **TTS** | 文字转语音（MiniMax TTS zh-CN）|
| **ICP 备案** | 中国大陆网站备案 |
| **公众号模板消息** | 微信公众号主动推送（需资质）|
| **微信支付 V3** | 微信支付最新版本（API v3）|
| **freemium** | 免费版 + 付费版组合 |
