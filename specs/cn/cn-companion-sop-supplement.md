## 1. 访客 SOP（公众号 → H5 → 注册前）⭐

**触发**：未注册用户从公众号 / H5 / 朋友分享进入

```
[第 1 步] 入口访问
   │
   │ 来源：
   │ • 公众号菜单 / 文章链接
   │ • 小红书 / 抖音引流
   │ • 朋友分享链接
   │ • 搜索引擎
   ↓
[第 2 步] H5 落地页
   │
   │ 显示：
   │ ┌─────────────────────────────────┐
   │ │ 🏠 小诺学伴                      │
   │ │                                   │
   │ │ 孩子不再孤军奋战                 │
   │ │ ✨ 1 mentor + 2 同学              │
   │ │ 📚 Socratic 引导                  │
   │ │ 📊 公众号周报                    │
   │ │                                   │
   │ │ [免费试用 30 天]                │
   │ │ [查看 3 道示例错题]              │
   │ │ [已有账号？登录]                 │
   │ └─────────────────────────────────┘
   │
   │ 【数据】无登录态，只看公开内容
   │ 【Cookie】localStorage 记录访问
   ↓
[第 3 步] 浏览示例
   │
   │ • 3 道示例错题（1/2 + 1/3 等）
   │ • 完整 Socratic 对话流程（录屏）
   │ • 公众号周报样例
   │
   │ 用户可点击"开始体验"但会跳到注册
   ↓
[第 4 步] 触发注册
   │
   │ • 点击"免费试用 30 天"
   │ • 点击"开始体验"
   │ • 点击"查看完整报告"
   │
   │ → 跳到 Onboarding SOP（注册）
   ↓
[第 5 步] 访客追踪（utm / cookie）
   │
   │ 记录：
   │ • 来源（公众号 / 小红书 / 朋友）
   │ • 停留时间
   │ • 点击"开始注册"次数
   │
   │ 数据用于运营优化
```

### 1.1 异常分支

| 异常 | 处理 |
|---|---|
| H5 加载慢 | skeleton + 进度条 |
| 朋友分享链接过期 | 提示"链接已过期" + 主入口 |
| 访客多次访问未注册 | 公众号模板消息"我们等你哦" |

### 1.2 API

| 端点 | 用途 |
|---|---|
| GET /api/landing/sample-mistakes | 示例错题（无需登录） |
| GET /api/landing/sample-report | 示例周报（无需登录） |
| POST /api/track/visit | 访客追踪（utm + 来源） |

## 2. 多孩管理 SOP（添加第 2/3 个孩子）⭐

**触发**：已付费家长添加第 2 / 3 个孩子

```
[第 1 步] 入口
   │
   │ • 主页"我的孩子"页 + 添加孩子按钮
   │ • 设置菜单"添加孩子"
   │ • 家庭版 CTA（单孩 → 升级时）
   ↓
[第 2 步] 检查套餐
   │
   │ ┌─────────────────────────────────┐
   │ │ 当前套餐：单孩 ¥99/月            │
   │ │ 已添加：1 / 1                    │
   │ │                                   │
   │ │ 添加第 2 个孩子？                │
   │ │ [升级到家庭版 ¥199/月]            │
   │ │ [继续单孩（添加受限）]           │
   │ └─────────────────────────────────┘
   │
   │ 【判定】已订阅家庭版 → 继续
   │ 【判定】单孩套餐 → 提示升级
   ↓
[第 3 步] 添加孩子表单
   │
   │ • 姓名 + 昵称
   │ • 出生日期（自动计算年级）
   │ • 教材（按年级推荐）
   │ • 模式（K12 / 学前）
   │
   │ 与首次注册 SOP 步骤 5 类似
   ↓
[第 4 步] 选 persona
   │
   │ 班主任：4 选 1（推荐与第一个孩子不同风格）
   │ 同学：4 选 2
   │
   │ 班主任锁定到学期末
   ↓
[第 5 步] 确认 + 入库
   │
   │ POST /api/kids
   │ 添加成功 → 主页孩子选择页显示新卡
   │
   │ 【限制】家庭版 ≤ 3 孩
   │ 【超出】提示"已达 3 孩上限"
```

### 2.1 异常分支

| 异常 | 处理 |
|---|---|
| 单孩套餐想加第 2 个 | 升级家庭版 CTA |
| 家庭版已 3 孩 | "已达上限，删除现有孩子可添加新孩子" |
| 添加时手机锁屏 | 数据本地缓存，重新打开可继续 |
| 孩子信息填写错误 | 编辑入口（24h 内） |

### 2.2 API

| 端点 | 用途 |
|---|---|
| GET /api/kids | 当前孩子的列表 |
| POST /api/kids | 添加孩子 |
| PATCH /api/kids/{id} | 修改孩子信息 |
| DELETE /api/kids/{id} | 删除孩子（家长操作）|

## 3. 升级家庭版 SOP（单孩 → ≤3 孩）⭐

**触发**：单孩家长想加第 2 个孩子，或家庭版 CTA

```
[第 1 步] 触发升级
   │
   │ • 添加第 2 个孩子时（自动）
   │ • 主页订阅 banner "升级家庭版"
   │ • 设置 → 订阅管理 → 升级
   ↓
[第 2 步] 选择新套餐
   │
   │ ┌─────────────────────────────────┐
   │ │ 当前：¥99/月 单孩                  │
   │ │                                   │
   │ │ 升级到：                            │
   │ │ • 家庭版 ¥199/月（≤3 孩）         │
   │ │ • 家庭版 ¥1999/年                  │
   │ │                                   │
   │ │ 已付金额抵扣：                     │
   │ │ ¥99/月 单孩 → ¥199/月 家庭版     │
   │ │ （剩余周期按比例抵扣）            │
   │ └─────────────────────────────────┘
   ↓
[第 3 步] 确认差价支付
   │
   │ POST /api/payment/upgrade
   │
   │ • 计算差价（按剩余天数）
   │ • 创建差价支付订单
   │ • 跳转微信支付 / 支付宝
   ↓
[第 4 步] 支付成功
   │
   │ • 订阅状态升级（plan = family）
   │ • kid_ids 包含所有孩子
   │ • 公众号模板消息"升级成功"
   │ • Web PWA 解锁"添加第 2 个孩子"
   ↓
[第 5 步] 添加第 2 个孩子
   │
   │ → 进入 SOP 2（多孩管理）
   │
   │ 用户可在 7 天内添加，超时套餐保留但不退
```

### 3.1 异常分支

| 异常 | 处理 |
|---|---|
| 支付差价失败 | 1 小时后重试 + 公众号提醒 |
| 7 天内未添加孩子 | 保留套餐但提示添加 |
| 降级（家庭 → 单孩）| 退订第 2/3 个孩子数据 |

### 3.2 API

| 端点 | 用途 |
|---|---|
| POST /api/payment/upgrade | 创建升级差价订单 |
| GET /api/payment/calc-diff | 计算差价 |
| PATCH /api/subscription | 更新套餐 |

## 4. 退订 / 注销 SOP ⭐

**触发**：用户主动取消订阅 / 注销账号

```
[第 1 步] 入口
   │
   │ • 设置 → 订阅管理 → 取消订阅
   │ • 设置 → 账号安全 → 注销账号
   │ • 公众号菜单"取消订阅"
   ↓
[第 2 步] 选择退订类型
   │
   │ ┌─────────────────────────────────┐
   │ │ ○ 取消订阅（保留数据 30 天）     │
   │ │ ○ 注销账号（删除所有数据）       │
   │ └─────────────────────────────────┘
   │
   │ 【PIPL】注销必须真的删除数据（30 天可恢复期）
   ↓
[第 3 步] 退订 / 注销原因（可选）
   │
   │ ┌─────────────────────────────────┐
   │ │ ○ 太贵                            │
   │ │ ○ 效果不明显                       │
   │ │ ○ 孩子不用了                       │
   │ │ ○ 改用其他产品                     │
   │ │ ○ 其他：____________              │
   │ └─────────────────────────────────┘
   │
   │ 用于运营改进，不强制填写
   ↓
[第 4 步] 确认
   │
   │ 【二次确认】
   │ ┌─────────────────────────────────┐
   │ │ ⚠️ 取消订阅后：                    │
   │ │ • 当前周期仍可用                  │
   │ │ • 周期结束后降为免费版             │
   │ │ • 错题数据保留 30 天              │
   │ │ • 30 天后未升级自动归档           │
   │ │                                   │
   │ │ [确认取消] [再想想]               │
   │ └─────────────────────────────────┘
   ↓
[第 5 步] 退订处理
   │
   │ • subscription.status = canceled
   │ • 公众号模板消息"已取消"
   │ • 当前周期仍可用（不退当期）
   │ • 周期结束后降为免费版
   │ • 免费版功能受限：
   │   - OCR 10 张/月
   │   - 错题本 50 道
   │   - 无 Socratic 完整版
   │   - 无公众号周报
   ↓
[第 6 步] 注销账号（特殊）
   │
   │ ⚠️ 此操作不可逆：
   │ • 立即停止订阅
   │ • 删除所有用户数据（30 天宽限期）
   │ • 删除错题记录 / 学习报告
   │ • 删除 persona 选择
   │ • 30 天后数据物理删除
   │ • 公众号推送"账号已注销"
   │
   │ 【PIPL 合规】数据真正删除（不仅是标记）
```

### 4.1 异常分支

| 异常 | 处理 |
|---|---|
| 30 天内恢复 | 重新订阅即恢复 |
| 退订后要求退款 | 7 天无理由退款（cn-region 法务）|
| 注销后误操作 | 30 天宽限期可联系客服恢复 |
| 重复扣款 | 立即退费 + 法务跟进 |

### 4.2 API

| 端点 | 用途 |
|---|---|
| POST /api/subscription/cancel | 取消订阅 |
| POST /api/account/delete | 注销账号（30 天宽限）|
| POST /api/account/restore | 30 天内恢复账号 |
| GET /api/account/export | PIPL 数据导出 |

## 5. 账号安全 SOP（修改密码 / 忘记密码）⭐

**触发**：用户修改密码 / 忘记密码 / 启用二次验证

```
[第 1 步] 入口
   │
   │ • 登录页"忘记密码"
   │ • 设置 → 账号安全 → 修改密码
   │ • 设置 → 账号安全 → 二次验证
   ↓
[第 2 步] 身份验证
   │
   │ ┌─────────────────────────────────┐
   │ │ 验证方式：                         │
   │ │ • 短信验证码（手机号）            │
   │ │ • 微信扫码（已绑定）              │
   │ └─────────────────────────────────┘
   ↓
[第 3 步] 修改密码
   │
   │ ┌─────────────────────────────────┐
   │ │ 新密码要求：                       │
   │ │ • 8-20 字符                       │
   │ │ • 至少 1 数字 + 1 字母             │
   │ │ • 不能与旧密码相同                │
   │ │                                   │
   │ │ [新密码] [确认密码]               │
   │ │ [提交]                             │
   │ └─────────────────────────────────┘
   ↓
[第 4 步] 二次验证（可选）
   │
   │ ┌─────────────────────────────────┐
   │ │ 启用二次验证：                     │
   │ │ • 短信验证码（默认）              │
   │ │ • 邮箱验证码                       │
   │ │                                   │
   │ │ [启用] [暂不启用]                 │
   │ └─────────────────────────────────┘
   ↓
[第 5 步] 完成
   │
   │ • 密码更新
   │ • 当前会话保持
   │ • 其他设备登录失效（强制重新登录）
   │ • 公众号推送"密码已修改"
```

### 5.1 异常分支

| 异常 | 处理 |
|---|---|
| 忘记密码验证失败 3 次 | 锁定 1 小时 |
| 新密码太弱 | 提示密码强度 |
| 二次验证短信发送失败 | 切换到邮箱验证 |

### 5.2 API

| 端点 | 用途 |
|---|---|
| POST /api/auth/reset-password | 重置密码 |
| PATCH /api/account/password | 修改密码 |
| POST /api/account/2fa | 启用二次验证 |

## 6. 推送设置 SOP（修改时间 / 关闭）⭐

**触发**：家长调整公众号推送偏好

```
[第 1 步] 入口
   │
   │ • 学习报告底部"推送设置"
   │ • 设置 → 通知设置
   ↓
[第 2 步] 当前设置
   │
   │ ┌─────────────────────────────────┐
   │ │ 📅 周报推送                        │
   │ │ • 频率：每周日 19:00              │
   │ │ • 方式：微信 + 邮箱                │
   │ │                                   │
   │ │ 🚨 错题提醒                        │
   │ │ • 频率：每天 20:00                 │
   │ │ • 阈值：错题 ≥ 3 道                │
   │ │                                   │
   │ │ 💡 学习建议                        │
   │ │ • 频率：每周六 10:00               │
   │ │                                   │
   │ │ [修改] [关闭全部]                 │
   │ └─────────────────────────────────┘
   ↓
[第 3 步] 修改
   │
   │ 修改项：
   │ • 频率（日 / 周 / 关闭）
   │ • 时间（拖动时间选择器）
   │ • 方式（微信 / 邮箱 / 关闭）
   │ • 错题阈值（1-10 道）
   ↓
[第 4 步] 保存
   │
   │ • POST /api/notification/preferences
   │ • 立即生效
   │ • 下次推送按新设置
   │ • 公众号模板"已更新"
```

### 6.1 异常分支

| 异常 | 处理 |
|---|---|
| 关闭所有推送 | 二次确认"将错过重要提醒" |
| 时间冲突（设置深夜）| 提示"建议 19:00-21:00" |
| 邮箱无效 | 提示"请先验证邮箱" |

### 6.2 API

| 端点 | 用途 |
|---|---|
| GET /api/notification/preferences | 当前推送设置 |
| PATCH /api/notification/preferences | 修改推送设置 |

## 7. 修改 persona SOP ⭐

**触发**：家长想换班主任 / 换同学

```
[第 1 步] 入口
   │
   │ • 主页孩子卡片"换班主任"
   │ • 设置 → 我的孩子 → 选 persona
   │
   │ ⚠️ 仅班主任可换，同学可增删
   ↓
[第 2 步] 班主任说明
   │
   │ ┌─────────────────────────────────┐
   │ │ ⚠️ 班主任锁定到学期末               │
   │ │                                   │
   │ │ 当前：小诺姐姐                    │
   │ │ 锁定到期：2027-01-31              │
   │ │ 剩余：150 天                      │
   │ │                                   │
   │ │ 换班主任会影响：                   │
   │ │ • 教学风格（prompt 替换）          │
   │ │ • 错题讲解连续性                   │
   │ │ • 孩子情感连接                     │
   │ │                                   │
   │ │ [继续换] [再想想]                 │
   │ └─────────────────────────────────┘
   │
   │ 【设计选择】班主任锁定防止频繁换
   │ 但提供学期末切换窗口
   ↓
[第 3 步] 选择新班主任（解锁后）
   │
   │ • 班主任：4 选 1
   │ • 同学：4 选 2（可增删）
   ↓
[第 4 步] 应用
   │
   │ • persona_instances 表更新
   │ • 新的 prompt 生效
   │ • 旧的对话历史保留
   │ • 公众号推送"已更新"
```

### 7.1 异常分支

| 异常 | 处理 |
|---|---|
| 班主任仍在锁定期 | 提示"X 天后解锁" |
| 孩子对原班主任有依赖 | 建议学期末再换 |
| 切换后家长后悔 | 7 天内可切回（不限次数） |

### 7.2 API

| 端点 | 用途 |
|---|---|
| GET /api/persona/instances | 当前孩子 persona |
| POST /api/persona/swap-mentor | 换班主任（锁定检查）|
| PATCH /api/persona/buddies | 修改同学 |

## 8. PIPL 数据请求 SOP（导出 / 删除）⭐

**触发**：家长行使 PIPL 权利（数据导出 / 删除）

```
[第 1 步] 入口
   │
   │ • 设置 → 隐私与数据 → PIPL 权利
   │ • 公众号菜单"我的数据"
   ↓
[第 2 步] 选择权利
   │
   │ ┌─────────────────────────────────┐
   │ │ PIPL 赋予您的权利：               │
   │ │                                   │
   │ │ [📦 数据导出]                     │
   │ │   导出您孩子的错题、学习报告、   │
   │ │   persona 选择等所有数据          │
   │ │                                   │
   │ │ [🗑️ 数据删除]                     │
   │ │   删除您孩子的所有数据            │
   │ │   （30 天宽限期可恢复）          │
   │ │                                   │
   │ │ [⏸️ 处理限制]                     │
   │ │   限制某些数据处理（如 AI 训练）  │
   │ └─────────────────────────────────┘
   ↓
[第 3 步] 身份验证
   │
   │ • 短信验证码（必填）
   │ • 微信二次确认
   │
   │ 【PIPL】必须严格验证身份
   ↓
[第 4 步] 数据导出（PDF + JSON）
   │
   │ ┌─────────────────────────────────┐
   │ │ 导出内容：                         │
   │ │ • 孩子信息（姓名 / 年级）         │
   │ │ • 错题记录（全部 + 图片）         │
   │ │ • 学习报告（每周 + 每月）          │
   │ │ • persona 选择 + 历史              │
   │ │ • 推送设置                         │
   │ │ • 订阅记录                         │
   │ │                                   │
   │ │ 格式：                             │
   │ │ • PDF（人类可读）                 │
   │ │ • JSON（机器可读）                │
   │ │                                   │
   │ │ 处理时间：7 天内                  │
   │ │ [确认导出]                         │
   │ └─────────────────────────────────┘
   ↓
[第 5 步] 数据删除
   │
   │ ⚠️ 此操作不可逆：
   │ • 立即停止订阅
   │ • 错题记录 → 删除
   │ • 学习报告 → 删除
   │ • persona 实例 → 删除
   │ • 30 天宽限期可恢复
   │ • 30 天后数据物理删除（不仅是标记）
   │
   │ 公众号模板"已申请删除"
   │ 30 天后推送"数据已物理删除"
```

### 8.1 异常分支

| 30 天内恢复 | 重新激活订阅 |
| 30 天后误操作 | 不可恢复（已物理删除）|

## 10. 未成年保护 SOP（时长 + 夜间）⭐

**触发**：超过每日时长 / 夜间使用 / 未成年人违规

```
[第 1 步] 时长监控
   │
   │ • 每天 ≤ 60 分钟（默认）
   │ • 周末 ≤ 90 分钟（可调整）
   │ • 21:00-7:00 禁用（默认）
   │
   │ 检测方式：前端计时 + 后端校验
   ↓
[第 2 步] 时长警告
   │
   │ ┌─────────────────────────────────┐
   │ │ ⏰ 您已经使用 50 分钟             │
   │ │ 建议休息一下哦                    │
   │ │ [继续 10 分钟] [现在休息]         │
   │ └─────────────────────────────────┘
   ↓
[第 3 步] 时长到达
   │
   │ ┌─────────────────────────────────┐
   │ │ ⏰ 您已经达到每日 60 分钟上限     │
   │ │                                   │
   │ │ 明天 7:00 后再来哦                 │
   │ │ [好的] [家长延长]                 │
   │ └─────────────────────────────────┘
   │
   │ 家长可输入 PIN 延长（每日 ≤ 30 分钟）
   ↓
[第 4 步] 夜间禁用
   │
   │ ┌─────────────────────────────────┐
   │ │ 🌙 现在是夜间休息时间             │
   │ │                                   │
   │ │ 21:00 后不再推荐学习               │
   │ │ 明天 7:00 见哦                     │
   │ │                                   │
   │ │ [好的]                            │
   │ └─────────────────────────────────┘
   │
   │ 强制退出（家长可全局关闭夜间模式）
   ↓
[第 5 步] 异常（连续违规）
   │
   │ • 孩子连续 3 天超时 → 公众号推送家长
   │ • 家长未响应 → 锁定账户 24h
   │ • 法务介入（疑似未成年人违规使用）
   │
   │ 【合规】PIPL + 未成年人保护法
```

### 10.1 异常分支

| 异常 | 处理 |
|---|---|
| 孩子修改本地时间绕过 | 后端校验（北京时间为准）|
| 家长同意延长时间 | PIN 验证（防孩子代家长）|
| 家长未设 PIN 验证 | 默认延长 30 分钟（可改）|
| 系统检测到疑似未成年人 | 法务 24h 介入 |

### 10.2 API

| 端点 | 用途 |
|---|---|
| GET /api/safety/usage-today | 今日使用时长 |
| POST /api/safety/extend | 家长延长（PIN 验证）|
| PATCH /api/safety/settings | 修改时长 / 夜间设置 |

## 13. 关键术语

| 术语 | 定义 |
|---|---|
| **访客** | 未注册用户，访问 H5 / 落地页 |
| **PIPL 数据请求** | 家长行使 PIPL 权利（导出 / 删除）|
| **注销** | 删除账号 + 30 天宽限 + 物理删除 |
| **退订** | 取消订阅 + 保留数据 30 天 |
| **升级家庭版** | 单孩 → ≤3 孩，差价支付 |
| **二次验证（2FA）** | 登录 / 敏感操作二次确认 |
| **未成年保护** | 时长限制 + 夜间禁用 + PIN 验证 |
| **班主任锁定** | 防止频繁切换，学期末解锁 |
| **客户分级响应** | 内容/隐私 24h / 服务 48h / 计费 72h |
